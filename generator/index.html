How to use

  • Seed: pick the seed that will be played.
  • Players: type the player name for buffs and/or debuffs.
  • Give to all: overrides the player names and applies to @a.
  • Select cards: check the buffs/debuffs you want.
  • Generate: copy the command and paste into MCSR Ranked.

Seeds

Some buffs/debuffs (like compasses and stronghold markers) need seed-specific coordinates. Add them here with spaces between X, Y and Z, e.g. -389 28 1488.
